# Nova Import · Catálogo Ámbar Perfumería

Catálogo interno para Nova Import S.A.S. con la línea Ámbar Perfumería.

## Estructura del proyecto

```
nova-import-bundle/
├── public/
│   ├── favicon.svg
│   └── images/products/    ← 25 fotos de productos Ámbar
├── src/
│   ├── App.jsx              ← Componente principal
│   ├── main.jsx             ← Entry point React
│   └── index.css            ← Tailwind base
├── index.html
├── package.json
├── vite.config.js
├── tailwind.config.js
├── postcss.config.js
└── .gitignore
```

## Correr localmente (opcional)

```bash
npm install
npm run dev
```

Abre `http://localhost:5173`
